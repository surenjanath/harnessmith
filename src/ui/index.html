How it works

    
The solver model attempts the goal with the project's base harness (system prompt, guardrails, memory, tool guidance, skills, sub-agents, scripts, hooks). The improver model reads those attempts and proposes harness edits along two dimensions: how the agent works (INV) and what a practitioner knows (DOM). Each edit is probed with a fresh attempt, and a composer merges what the evidence supports. The selector then picks the best final output without seeing which harness made it, and writes a lesson into the project library for the next goal. Budget per goal: 4k solver runs and 3k improver sessions.
